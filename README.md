# SCT_DS_1

This project is a Google Colab notebook that demonstrates how to get started with the Gemini API. It shows how to perform various tasks, including text generation, using grounding capabilities to create reports, extracting structured data from PDFs, and creating illustrations from text descriptions.

Key Features ✨
Gemini API Integration: Learn how to use the Gemini API directly within a Google Colab environment.

Text Generation: Generate text with a simple function call.

Report Generation: Use Gemini's grounding capabilities to create a report on a company based on information found on the internet.

PDF Data Extraction: Extract invoices and form data from a PDF in a structured way.

Text-to-Illustration: Create illustrations based on a whole book using Gemini's large context window and Imagen.

Technologies Used 🔧
Google Colab: An interactive notebook environment that runs in the cloud.

Gemini API: Google's latest and most capable AI model.

Python: The programming language used in the Colab notebook.

Installation/Setup ⚙
Go to Google AI Studio and log in with your Google account.

Create an API key.

Open the Colab notebook and replace the placeholder with your API key.
